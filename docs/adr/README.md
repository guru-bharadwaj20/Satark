# Architecture Decision Records

Each ADR records one significant decision. Copy [`ADR-000-template.md`](ADR-000-template.md) to
`ADR-NNN-short-title.md` using the next free number, e.g. `ADR-001-kubeadm-over-k3s.md`.

Statuses: `Proposed`, `Accepted`, `Superseded by ADR-NNN`, `Deprecated`. ADRs are never deleted;
supersede them instead.
